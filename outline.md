# Dragon 2048 - Структура проекта

## Основные файлы
1. **index.html** - Главная страница с игрой
2. **dragon-2048.js** - Игровая логика и механика 2048
3. **resources/** - Папка с ресурсами
   - dragon-egg.png - Яйцо дракона (2)
   - baby-dragon.png - Дракончик (4)
   - young-dragon.png - Юный дракон (8)
   - dragon.png - Дракон (16)
   - fire-dragon.png - Огненный дракон (32)
   - ice-dragon.png - Ледяной дракон (64)
   - lightning-dragon.png - Электрический дракон (128)
   - shadow-dragon.png - Теневой дракон (256)
   - golden-dragon.png - Золотой дракон (512)
   - ancient-dragon.png - Древний дракон (1024)
   - mega-dragon.png - Мегадракон (2048)

## Этапы разработки
1. Создание HTML структуры с игровым полем
2. Реализация базовой механики 2048
3. Интеграция пиксельных изображений драконов
4. Добавление плавных CSS анимаций
5. Реализация звуковых эффектов
6. Финальная оптимизация и тестирование
