# Dragon Evolution 2048

Это увлекательная игра-головоломка, основанная на классической 2048, но с увлекательным дополнением — эволюцией драконов! Соединяйте одинаковые плитки, чтобы открывать новых драконов и достичь финальной стадии эволюции.

## Как играть

- **Цель:** Достичь плитки 2048, чтобы открыть Мегадракона.
- **Движение:** Используйте клавиши со стрелками или проведите пальцем по экрану (на мобильных устройствах), чтобы перемещать плитки.
- **Объединение:** Когда две плитки с одинаковыми драконами сталкиваются, они объединяются в одну, развиваясь в следующего дракона в цепочке.
- **Новые плитки:** После каждого хода на поле появляется новая плитка.
- **Конец игры:** Игра заканчивается, когда на поле не остается свободных клеток и невозможно совершить ни одного хода.

## Эволюция драконов

Откройте 11 уникальных драконов, начиная с яйца и заканчивая легендарным Мегадраконом. Каждая новая эволюция приносит больше очков и приближает вас к победе!

## Как запустить

1. Клонируйте этот репозиторий.
2. Откройте файл `index.html` в вашем веб-браузере.
3. Наслаждайтесь игрой!
